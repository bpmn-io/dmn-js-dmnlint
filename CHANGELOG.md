# Changelog

All notable changes to [dmn-js-dmnlint](https://github.com/bpmn-io/dmn-js-dmnlint) are documented here. We use [semantic versioning](http://semver.org/) for releases.

## 0.2.0

* `FEAT`: use translate service ([#1](https://github.com/bpmn-io/dmn-js-dmnlint/pull/1))
* `FEAT`: support `info` reports
* `FIX`: show rule failures (`rule-error`) as separate category on diagram level
* `FEAT`: source colors and corner radius from `@bpmn-io/theme` tokens. Override the `--bio-*` tokens or `--djsl-*` instead
* `DEPS`: update to `min-dash@5.1.0`
* `DEPS`: update to `min-dom@5.3.0`
* `DEPS`: update to `diagram-js@15.28.1`

### Breaking Changes

* `DEPS`: require `dmnlint@^2.0.0` as peer dependency

## 0.1.1

* `FIX`: fix config setter

## 0.1.0

* `FEAT`: initial release :tada:
